# Prompt — شروع پیاده‌سازی

این Project Specification را به‌عنوان منبع حقیقت پروژه در نظر بگیر.

ابتدا فایل‌های زیر را کامل بخوان: `AGENTS.md`, `PROJECT_BRIEF.md`, `REQUIREMENTS.md`, `ARCHITECTURE.md`, `ARCHITECTURE_DECISIONS.md`, `ROADMAP.md`, `TEST_STRATEGY.md`.

سپس فقط TASK 00 را اجرا کن.

مهم:
- قبل از پیاده‌سازی، امکان‌سنجی واقعی Telegram Web را ثابت کن.
- هیچ `api_id`, `api_hash` یا Bot Token درخواست یا استفاده نکن.
- هیچ endpoint داخلی یا API خصوصی Telegram را فراخوانی نکن.
- پیچیدگی غیرضروری ایجاد نکن.
- قبل از کدنویسی هر Task تست‌های آن را طراحی و بنویس.
- پس از تغییر کد، تست‌ها، Typecheck و Lint را اجرا کن.
- تست Fail را پنهان یا Skip نکن.
- پس از Pass شدن کنترل‌ها، تغییرات همان Task را Commit کن.
- به Task بعدی نرو مگر Acceptance Criteria Task فعلی تکمیل شده باشد.
- در پایان هر Task گزارش تغییرات، تست‌ها، محدودیت‌ها و Commit را ارائه کن.

در این مرحله هیچ قابلیت اضافی خارج از TASK 00 نساز.
